# AI Coding Agent — Code Cafe Coding Challenge

This repository currently contains **only the development prompts** for the
AI Coding Agent challenge — no application code has been implemented yet, as
requested.

See [`ai-coding-agent-prompts.txt`](./ai-coding-agent-prompts.txt) for the
full, ordered set of prompts needed to build the application, using:

- **Backend:** Java 21 + Spring Boot
- **Frontend:** React
- **Database:** MySQL (local instance)
- **Local AI model:** Ollama (local instance)

The prompt pack includes 22 prompts (Prompt 0 for scaffolding through Prompt
21 for final documentation) plus a traceability matrix mapping every
requirement (R1–R40) from the challenge brief to the prompt(s) that
implement it.
